Q1: Why might we consider using Git?

Answer: Git is great for collaboration as it is way easier to use git to make sure everyone is working on the latest version of the repo by consistently pulling and you can push the code to the repo too. Git makes sure the whole team is on the same page.

Q2: What field could data science be applied to? Give an Example.

Answer: Data science can be applied to fintech companies. For example, over the summer I worked at a fintech startup where I used data science to analyze loan repayment patterns and I worked on an Early warning system for loan defaulters.


Q3: What is the difference between Merging and Rebasing?

Answer: Merging basically combines 2 branches and rebasing basically does all the commits from one branch to another.
